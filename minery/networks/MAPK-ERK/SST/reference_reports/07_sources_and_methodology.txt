================================================================================
C. METHODOLOGY
================================================================================

  1. ENTITY EXTRACTION
     - Parsed all Prolog event/3 predicates from kBase.pl
     - Extracted unique entity names (subject + object pairs)
     - Cross-referenced with biotypes-kbs/ files for type classification
     - Counted ~380 unique entities interacting with COVID-19

  2. EXPERT OBJECT CROSS-REFERENCING
     - Mapped 25 expert objects from aligned.pl against kBase.pl
     - Identified which expert objects lack COVID-19 direct links
     - Found 8 of 25 expert objects without COVID-19 events in kBase

  3. SYNONYM DETECTION
     - Used synonyms.pl (443 entries) to build synonym expansion list
     - Programmatic search for event pairs where subject/object are synonyms
     - Identified 9 synonym groups affecting 38+ event pairs
     - Flagged NEOPLASMS/MICA artifact as false synonym

  4. HYPOTHESIS GENERATION
     - Prioritized entities with multiple unexplained negative/positive
       correlations to expert objects
     - Focused on actionable targets (existing drugs/inhibitors)
     - Cross-validated against PubMed for novelty assessment
     - Selected 5 hypotheses with strongest evidence-to-novelty ratio

  5. KNOWLEDGE BASE ENRICHMENT
     - Proposed 22 new interactions based on transitive relationships
       between expert objects and correlated entities
     - Updated aligned.pl with 27 new PubTator-aligned objects
     - Created expert_objects.txt with expanded object list
