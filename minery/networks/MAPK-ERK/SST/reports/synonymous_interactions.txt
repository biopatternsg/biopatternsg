1. S6K ≡ RPS6KB1 (aligned_as / gene synonym)
--------------------------------------------------------------------------------
aligned.pl: aligned_as('S6K', ['RPS6KB1', 'S6K', 'P.S6K']).
synonyms.pl: synonyms('RPS6KB1', ['RPS6KB1','P70 S6K','S6K','P70S6K',...]).

kBase.pl contains events using both names:

  Using 'RPS6KB1' (canonical PubTator name in kBase):
    event('RPS6KB1',negative_correlation,'SIROLIMUS')   [line 12-13]
    event('SIROLIMUS',negative_correlation,'RPS6KB1')   [line 13]

  Using 'S6K' (expert object name, expert_objects.txt line 14):
    (no direct 'S6K' event in kBase.pl; 'S6K' appears only via aligned_as)

Impact: S6K and RPS6KB1 are the SAME gene (ribosomal protein S6 kinase
beta-1 / p70 S6K). All 'S6K' references (expert object) map to kBase
'RPS6KB1' events. TRUE synonym.
Documentation: aligned.pl:86; synonyms.pl RPS6KB1 entry; kBaseDoc lines
for RPS6KB1 events (same sentences as SIROLIMUS block, PMID 20068168).

--------------------------------------------------------------------------------

synonyms.pl: synonyms('CDKN1B', ['CDKN1B','KIP1','P27KIP1','P27','P27 KIP1',...]).

kBase.pl contains events using both names:

  Using 'DCTN6':
    event('OCTREOTIDE',positive_correlation,'DCTN6')   [line 4-5]
    event('DCTN6',positive_correlation,'OCTREOTIDE')   [line 5]
    event('DCTN6',positive_correlation,'SIROLIMUS')    [line 30]

4. SSTR2 ≡ SSTR5 overlap (receptor subtype synonym pollution)
--------------------------------------------------------------------------------
synonyms.pl: synonyms('SSTR2', ['SSTR2',...,'SSTR5',...]).
synonyms.pl: synonyms('SSTR5', ['SSTR5',...,'SSTR2',...]).
aligned.pl: aligned_as('SSTR5', ['SSTR2','SSTR5']).

kBase.pl contains events using both names:

  Using 'SSTR2':
    event('OCTREOTIDE',association,'SSTR2')          [line 2462]
    event('NEUROENDOCRINE TUMORS',association,'SSTR2') [line 10959]

  Using 'SSTR5':
    event('OCTREOTIDE',association,'SSTR5')          [line 2469]
    event('NEUROENDOCRINE TUMORS',association,'SSTR5') [line 10957]
    event('SSTR5',positive_correlation,'NEUROENDOCRINE TUMORS') [line 65289]

Impact: PubTator assigned SSTR5 to SSTR2 synonyms and vice versa, and
aligned_as('SSTR5',['SSTR2','SSTR5']) conflates them. In the NET context,
SSTR2 and SSTR5 are distinct receptor subtypes but BOTH bind octreotide and
are expressed in NETs (PMID 35020172: "OCT interacts with somatostatin
receptors 2 and 5"). Treated as TRUE synonyms for the octreotide/NET axis
but FLAGGED for subtype-specific review (SSTR2 vs SSTR5 may have distinct
drug affinities and signaling).
Documentation: synonyms.pl SSTR2/SSTR5 entries; aligned.pl:89; kBaseDoc
PMID 35020172, 7631795, 20529830, 28155055.

7. PUBTATOR ARTIFACT TO EXCLUDE: NEOPLASMS ≡ 'MICA' (microinvasive carcinoma)
--------------------------------------------------------------------------------
Pattern documented in reference_reports/02_synonymous_interactions.txt
(STRUCTURE/FORM ONLY): synonyms('NEOPLASMS',[...,'MICA',...]) where 'MICA'
means "microinvasive carcinomas" ≠ the MICA gene.

This artifact is NOT present in the SST expert object set (MICA is not an
expert object here). It is flagged as a pattern to AVOID when expanding
synonyms for the NEOPLASMS/CARCINOMA NEUROENDICRINE disease supertype.
If NEOPLASMS events were ever equated to MICA-gene events, they would be
FALSE synonymous pairs (12 confirmed false pairs in the COVID-19 reference
study). EXCLUDED from this study's deduplication.
