3. Contradictions / conflation risks
--------------------------------------------------------------------------------

C1. LANREOTIDE (expert_objects.txt line 17) is NO_ALIGNED (aligned.pl:76).
    It appears in only 3 kBase.pl events but none tied to the two target
    diseases. Because the constraint requires PubTator-aligned names only in
    new reports, LANREOTIDE is EXCLUDED from new events; OCTREOTIDE (aligned)
    is used as the somatostatin-analogue representative.

C2. SSTR2/SSTR5 synonym overlap:
    synonyms('SSTR2',[...,'SSTR5',...]) and synonyms('SSTR5',[...,'SSTR2',...]).
    aligned_as('SSTR5',['SSTR2','SSTR5']). → SSTR2 and SSTR5 events may be
    conflated. Treated as TRUE synonyms for NET context but flagged for review.

C3. SST aligned_as includes 'GROWTH HORMONE-SECRETING PITUITARY ADENOMA' and
    'GASTROINTESTINAL STROMAL TUMORS' (aligned.pl:88) — these are diseases,
    not the SST peptide. Risk of false matches when expanding SST synonyms.
    Mitigation: use canonical 'SST' name only in new events.

C4. EVI1 aligned_as includes 'RUNX1' (aligned.pl:103) — RUNX1 is an expert
    object (line 23). EVI1/RUNX1 events risk conflation. Mitigation: keep
    canonical names separate.

C5. NEOPLASMS/MICA false-synonym artifact (documented in reference
    reports/02_synonymous_interactions.txt — form reference only): 'MICA'
    appears in NEOPLASMS synonyms meaning "microinvasive carcinoma" ≠ MICA gene.
    Not present in this SST expert object set; noted as a pattern to avoid.

C6. CARCINOMA NEUROENDICRINE (expert object line 69; aligned.pl:72) has NO
    direct kBase.pl event (grep count = 0). It is represented only as a disease
    biotype. To correlate objects with it, use the NEUROENDOCRINE TUMORS event
    set plus the wellKnownRules.pl subsumption
    wkr_carcinoma_neuroendocrine(X) → wkr_neuroendocrine_tumors(X).

C7. biotypes-kbs/variants.pl contains ~1,018 variants (P.G12V, P.V600E,
    P.T790M, P.L858R, etc.) but NONE are linked by event/3 to expert objects or
    target diseases in kBase.pl. Variants are present as biotypes but uncorrelated
    in the event graph → variant correlation must be inferred via gene membership
    (e.g. variants of EGFR/KRAS/TP53) rather than direct events.
